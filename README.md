# Henrique Guimarães

**Engenheiro de Dados Industriais · IIoT**

---

Atuo com engenharia de dados industriais no setor de óleo e gás, com foco
em integração entre tecnologia operacional (TO) e tecnologia da informação
(TI), ingestão em data lake e construção e orquestração de pipelines para
plataformas analíticas em grandes operações industriais.

Mestre em Engenharia de Sistemas e Automação (UFLA), com background
em visão computacional aplicada à instrumentação industrial.

## Sobre este repositório

**Laboratório de Projetos em IIoT** — espaço onde mantenho projetos
técnicos em engenharia de dados industriais, explorando o ecossistema
IIoT em arquiteturas abertas e tecnologias adotadas em ambientes
industriais.

O objetivo é compartilhar conhecimento e insights em projetos de dados
para IIoT.

## Áreas de interesse

- Engenharia de Dados Industriais e IIoT
- Mensageria industrial (MQTT, Kafka, Sparkplug B)
- Bancos de séries temporais e observabilidade
- Pipelines de streaming e batch
- Integração TO/TI

- **Linguagens:** Python · SQL · PySpark
- **Streaming & mensageria:** MQTT · Kafka · RabbitMQ · Node-RED

- **Dados:** InfluxDB · Databricks · Spark

- **Industrial:** Ignition · OPC-UA
